kybase 是自托管的知识库服务：把文件摄入成索引，检索时先给判定、再给 带出处的原文片段。它不生成回答，只把证据交给你的 Agent。

回答可以生成，出处不能。

Agent 需要的不是一个更像人的答案，而是一段它引用得起、你核得动的原文。

检索先给判定，再给原文。

大多数检索只回一串分数。kybase 先回答另一个问题：这份资料到底答不答得上。 fit 是内容结论，none 不是故障。

  1. 01

    判定先于原文

    summary 一句话说清候选与收敛结果，distribution 给出分布， decision 记录这次按什么收敛。原文排在它们之后。

    strong weak none unknown
  2. 02

    页码只在能核对时出现

    页码跟着文档自己的分页标记走；对不上就返回 null——报一个翻不到原文的页码， 比不报更糟。每条命中还标出是哪条通道捞上来的。

    “嵌入维度建议不超过 2000，推荐 1024……”

    部署手册-NAS.md p.7 hybrid · 0.71
  3. 03

    收敛，是一页一页翻

    keep 是一页几条，top_k 是这次能翻到的总量。 按 offset / next_offset 翻到 null， 判定在每一页上逐字相同。

    第 1 页 · keep 5 · offset 0
    第 2 页 · offset 5
    第 3 页 · offset 10
    next_offset: null

摄入：所有格式先变成 Markdown

上传、逐文件探测、解析、切块、向量化、索引。异步流水线带租约与退避， 中途断了能接着跑；云端与本地解析按文件动态路由。

切块：每块都记得自己从哪来

一块文本带着标题路径与页码离开原文。页码与文档自己的分页标记不自洽时， 宁可留空，也不报一个翻不到的页。

检索：两个通道各说各的，再合成一个判定

向量与 BM25 各自出候选，RRF 融合之后先看分布，再决定留几条。 命中太多时按 keep / min_score / per_doc 收敛。

引用：把这段原文和它的来路一起交出去

调用方拿到的是片段、页码、通道与分数。判定说资料答不上，就不该拿这几条噪声编答案。

三条路径，同一套语义。

同一个检索、同一个判定、同一把 API Key。接入方式不同，返回的东西完全一样。

Claude Desktop · Cursor · 任意 MCP 客户端 
{
  "mcpServers": {
    "kybase": {
      "type": "http",
      "url": "http://kb.example.com:8765/mcp",
      "headers": {
        "Authorization": "Bearer <你的 API Key>"
      }
    }
  }
}
  • Streamable HTTP，路径 /mcp；每个请求都要凭据，没有匿名放行。
  • 握手时 serverInfo.version 带工具面指纹，客户端据此判断契约有没有变过。
任何能发 HTTP 的系统 
curl -sS -X POST http://kb.example.com:8081/api/v1/search \
  -H "Authorization: Bearer $KYBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "嵌入模型怎么标定？",
    "kb_ids": ["kb_xxx"],
    "top_k": 5
  }'
  • 前缀 /api/v1，路径即版本；OpenAPI 在 /api/v1/openapi.json。
  • kb_ids 必填；判定与原文在同一个响应里，顺序固定。

鉴权只有一种

每个请求带 Authorization: Bearer <API Key>。 Key 的作用域决定它能看哪些库、能写什么；作用域外的请求按没权限拒绝。

库范围是钥匙的属性

同一把钥匙可以只读一座库，也可以管全部；分享、管理员都是知识库语义的资产。

管理台不是装饰。

摄入看进度、检索看命中、模型看用途、任务看失败。真实运行截图，数据来自演示实例。

一条命令，然后是四个决定。

带 docker 的干净机器，四件套一起起；已有 PostgreSQL 与 MinIO 的机器，只起应用层。

  1. 01

    起容器

    PostgreSQL（pgvector）、MinIO、后端与前端，四个服务一起。

  2. 02

    登记嵌入模型

    模型身份由注册表承担，不塞进环境变量。没登记，建库会被拒。

  3. 03

    建库、上传

    文件进去，摄入流水线自己跑；断了能接着跑。

  4. 04

    给 Agent 一把钥匙

    建 API Key，按库给范围；MCP、REST、Skill 用同一把。
