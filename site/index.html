给 Agent 插一块知识库。

kybase 是一个 MCP 知识库服务。把 PDF 和 Word 交给它，Agent 就能在会话里完成上传、解析、管理和检索； 命中返回原文片段、页码与标题路径。任何支持 MCP 的 Agent 都能接入。
也支持 REST 与 Skill。

01 / 工具

11 个工具，
覆盖知识库全流程。

接入、上传、解析、管理、检索都在 MCP 工具中。Agent 按状态调用，每一步都有明确的返回。

    工具契约带指纹 surface_fingerprint。

    请求使用 Authorization: Bearer <API Key> 鉴权。

    02 / 返回

    先给判定，
    再给原文。

    响应包含 summary、distribution、decision 和命中片段。 Agent 可以据此判断资料是否相关，并决定引用哪些内容。

    • fit 四档：strong 相关 · weak 部分相关 · none 不相关 · unknown 未知
    • score 是融合分，similarity 是余弦相似度
    • basis 标明命中来自 vector 或 fulltext

    05 / 调参

    每次检索，
    参数由 Agent 决定。

    检索模式和参数随请求传入。分布会给出建议值，Agent 可以直接采用，也可以按需要调整。

    distributionSTRONG
    38 candidates · 4 survived
    0.37baseline 0.5310.712
    资料吻合度高，按每篇最相关的结果收敛。

    分布、基线与建议值在同一次返回中。

    mode
    向量 + 词面，RRF 融合
    keep 4 一页返回条数
    min_score 0.531 余弦相似度下限
    per_doc null 每篇文档最多条数
    decided_by suggested 参数来源

    下一次调用

    {"keep": 4, "min_score": 0.531, "per_doc": null}

    采用分布建议的参数。

    07 / 部署

    一条命令，
    启动服务。

cd kybase

docker compose -f deploy/docker-compose.yml up -d --build
