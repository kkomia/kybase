# 界面设计 v0.2 —— 纸与墨 · 信号蓝

> 这一版是 2026-10 的**界面重做**：把管理台的视觉语言从上一版的"对齐 Kimi 的灰白仿作"
> 换成一套自己的、有主张但仍克制的系统。代码落点是 `frontend/src/styles/**`、
> `frontend/src/features/layout/**`、`frontend/src/ui/**` 与各域页面。
>
> 本文写的是**决定与理由**，不是逐条 CSS 说明。逐处取值仍在代码注释里
> （`tokens.css` / `themes/*.css` / `ui/*.tsx` 的文件头），两边不重复。

## 0. 一句话

**安静的实验室，活着的仪表。**

纸感的底、墨色的字、一个只在"动作 / 当前 / 数据"三处出现的钴蓝；
所有运动都短、轻、有因果（切换、到达、聚焦），没有装饰性动画。

## 1. 这版要解决的四件事

上一版并不丑，但它有四个结构性问题，这次逐个改掉：

| 问题 | 现象 | 这版怎么改 |
| --- | --- | --- |
| **字阶塌了** | 页标题 18px、正文 15px，只差 3px；KPI 数字和标签一样重，一屏里没有主角 | 页标题 28 / 分区 19 / 正文 15 / 元信息 13.5 / 微标签 12；仪表数字单开一档 32 |
| **颜色没有主张** | 暖白底 + 通用蓝，像 Kimi 的灰版；蓝到处都是，于是哪里都不重要 | 一个钴蓝只留给"动作 / 当前 / 数据"；其余全部是白面 + 墨色四级 |
| **靠描边分块** | 满屏 1px 灰线，界面像线框图；卡片、面板、表格分不出层级 | 层级交给**白面 + 投影**；描边只做兜底；发丝线只出现在表头与行之间 |
| **几乎没有动效** | 只有 hover 换底色；换页是瞬时的，数据到达是跳出来的 | 三档基础动效 + 一档数据动效：页面进场、滑动指示条、数字滚动、图表入场、按下反馈 |

## 2. 品类与首屏

- **品类**：自托管知识库管理台（文档入库 → 解析 → 切块 → 检索 → 对外 MCP 接入）。
  局域网、桌面为主、每天用几分钟的量级。
- **首屏主角**：概览页的"仪表带"——知识库 / 文档 / 切块 / 体积 / 近 365 天入库；
  第二主角是知识库卡片（找到那个库）。
- **参考的标杆**：Linear（密度与克制的动效）、Notion（纸张感与留白）、
  Vercel Dashboard（数字排版）、Kimi（暖白与墨色，**只保留这一层，其余不再跟**）。

## 3. 视觉语言

### 3.1 面与墨

三级面：纸（`--bg-canvas` #F1EEE8）→ 面（`--bg-surface` #FFF）→ 浅面（`--bg-subtle`）。
内容卡是"纸上一扇窗"：圆角 22、1px 发丝边、一层暖黑投影（`--shadow-card`）。
**静态内容也带投影**——这是这一版与上一版最大的观感差别：分块靠光影，不靠线。

墨色四级，全部按对比度契约取值（不是审美偏好）：

| 令牌 | 浅色实测 | 用途 |
| --- | --- | --- |
| `--text-primary` | 17.4:1 | 标题、正文、名字、数字 |
| `--text-secondary` | 6.0:1 | 说明、次级读数、表头标签 |
| `--text-tertiary` | 4.8:1 | 元信息、时间、计数（12–13.5px 仍达标） |
| `--text-quaternary` | 3.3:1 | 占位文字、图标、非文本边界（≥3:1） |

### 3.2 色彩

- **信号蓝** `#2F54EB`（钴蓝，比上一版照抄 Kimi 的 `#1783ff` 往靛蓝推了 12°）：
  只出现在主按钮、当前导航项、聚焦环、图表主色与"当前"标记上。
  白字压在蓝底上 5.6:1。
- **语义色**：成功 `#0B7A55`、警告 `#96600A`、危险 `#C32B34`（浅色取达标档；
  深色提亮）。语义色只用于状态，不用于"强调"。
- **数据色**四支：蓝 / 青 / 琥珀 / 紫（`--chart-1..4`），图表内也只用这四支。

### 3.3 字阶

系统字体栈（局域网自托管产品，首屏不等 webfont）。六档 + 仪表数字：

```
28 页标题 · 19 分区标题 · 15 正文 · 13.5 元信息 · 12 微标签 · 10.5 仅拉丁字母与数字
32 仪表数字（行高 1.05，字距 -0.035em）
```

中文正文行高 1.55（上一版 1.47 偏密）；长篇阅读面仍用 1.75。

### 3.4 间距与圆角

4px 网格，保留 6 / 10 两个"成对关系"档（图标与文字、标题与副标题）。
圆角收成三档尺度：控件 10 / 卡片 18 / 浮层 22（上一版 10/12/16/20/24 五档太碎）。
徽章改胶囊（999px）：它现在承载状态短语；方角（6px）留给"种类 / 计数"。

### 3.5 图表

ECharts 的 option 仍然只写主题令牌（`var(--accent)` 这类），由 `EChart` 统一解析成
canvas 能吃的色值；坐标轴、网格线、tooltip 的样式统一在那一层给。
这一版只加了两件事：**入场动画 620ms / cubicOut**，以及趋势线的面积渐变。

## 4. 结构

### 4.1 应用壳

```
┌ 256px 侧栏 ─┬─ 内容卡（圆角 22，纸底上浮 8px）──────────────┐
│ kybase 字标 ◧ │ 顶栏 56：面包屑 · ● 在线 · 明暗切换           │
│              ├──────────────────────────────────────────────┤
│ 工作台        │ 页头：28px 标题 + 一行现状 + 右侧动作          │
│  概览         │                                              │
│  所有知识库    │ 内容：仪表带 / 卡片 / 面板                    │
│  任务中心     │                                              │
│ 接入与配置     │                                              │
│  接入 · 模型  │                                              │
│  API 密钥     │                                              │
│ ╭ 账号 ╮     │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- **两个分组是静态标签**（没有折叠动作）：前三项是日常看什么，后三项是外面怎么接进来。
- **当前项的滑动指示条**是壳里唯一"有自己的动画"的元素：换页时 3px 竖条滑到新位置，
  260ms、轻过冲。它把"换了一页"变成一次位移而不是一次闪烁。
- **顶栏**只放全局成立的三件事：我在哪（面包屑）、服务在不在（心跳绿点）、明暗。
- 折叠态 72px，只留图标；文字用 `max-width` 收到 0，宽度动画不断。

### 4.2 页头配方

每页第一屏都是同一形状：**28px 标题 + 一行具体现状 + 右侧主操作**。
现状句写"现在是什么"，不写"本页用于……"：

- 概览：`9 个知识库 · 230 篇文档 · 28,598 个切块`
- 知识库：`9 个知识库 · 230 篇文档`
- 任务中心：`246 个任务 · 12 个失败 · 队列 0 条`
- 接入：`MCP 地址已配置 · 11 个对外工具`
- 模型：`3/3 用途已绑定 · 3 家供应商 · 5 个模型`
- API 密钥：`共 9 把 · 1 把只读`

### 4.3 卡片与列表

- **卡片**（`.surface-card`）：白面 + 18 圆角 + `--shadow-card`；可点的加悬停抬 2px。
- **仪表带**：一张卡、五格，格与格之间用发丝线切开——不是五张各自描边的卡。
- **面板**（`.panel` / `.panel-head` / `.panel-row`）：表格型清单；行高 52，
  悬停整行给 alpha 底，行之间 1px 发丝线，表头自带一层浅底。
- **不在卡片里套卡片**：卡片的下一层要么是内容，要么是发丝线。

## 5. 动效

三档时长 + 一档数据：

| 档 | 时长 | 用在哪 |
| --- | --- | --- |
| fast | 120ms | 颜色、底色（悬停 / 选中 / 聚焦） |
| mid | 200ms | 小东西的位移（图标、箭头、指示条、按下） |
| slow | 320ms | 有体量的东西（页面进场、折叠、抽屉） |
| data | 520ms | 数字滚动、图表入场（与交互无关，可以慢一点） |

曲线：`--ease-out`（快进慢出）是主曲线，`--ease-spring` 只给指示条。

**这一版落地的六处**：

1. **路由进场**：换页时内容上浮 10px + 淡入 320ms（`AppShell` 用 pathname 作 key，
   同页内的 tab / 查询参数变化不重播）；
2. **导航指示条**：换页 260ms 滑到新位置（`SideNav` 量当前项位置）；
3. **数字滚动**：概览页五个大数从 0 走到目标值（520ms 缓出）；
4. **图表入场**：三条 ECharts 620ms cubicOut；
5. **按下反馈**：所有按钮 `active:scale-[0.98]`；
6. **悬停抬起**：可点卡片 / 知识库卡悬停上浮 2px + 投影加深。

**减少动态效果**：`prefers-reduced-motion: reduce` 下以上全部退回瞬时；
`tokens.css` 与 `index.css` 各有一道兜底（后者覆盖 `src/ui` 里上游带来的动画）。

| 页面 | 这一版改了什么 |
| --- | --- |
| 登录 / 首次设置 | 纸上一张卡（400px、圆角 22、`--shadow-raised`），背景一片极淡的品牌蓝光 + 一枚放大的行星轨道线；输入框 36 高、按钮 40 高 |

| 任务中心 | 运行负载改成五张仪表卡（环 + 进度条 + 大数）；任务表行高 52、状态胶囊、失败行淡红底；分页保持 |

## 7. 与上一版的取舍

**保留**：

- 令牌驱动的做法（组件只认 `--*` 变量，写死色值仍然禁止）；
- 焦点环只画一层、可达性契约（正文 ≥4.5:1、占位 ≥3:1）、减少动态效果；
- 布局骨架（左侧导航 + 内容区）与信息架构（页面、路由、侧栏六项）；
- 「一屏一个主角」「不写解释性小字」的文案纪律。

**推翻**：

- 「全面对齐 Kimi」的取值（暖白 `#fbfaf9`、18px 页标题、墨色主按钮、4px 方角徽章、
  240px 侧栏）——对齐本身没有产生品牌，只产生了"像另一个产品"；
- 「静态内容不用阴影、只有浮层才用」——这一版靠投影分块；
- 「名词性徽章默认方角」——默认改胶囊。

**没做**：

- 不引 webfont（局域网首屏不等字体）；
- 不做移动端独立导航（管理台以桌面为主；窄屏侧栏自动收成 72px 图标栏）；
- 不重写 `src/ui/**` 里未参与本次改版的原语（下拉菜单 / 抽屉 / 命令面板等
  只通过令牌继承了新配色与圆角）。

## 8. 验收

- 桌面 1440×900、窄屏 900 / 390 宽各看一遍；
- 深浅两套主题都过；
- `prefers-reduced-motion` 下无动画；
- `pnpm lint` / `pnpm typecheck` / `pnpm test` 全绿。

## 9. 维护指引（新增页面时的默认做法）

1. 页面根用 `.page-shell`，页头用 `PageShell`（`features/misc/shared/composites`）
   的 `title` + `subtitle` + `actions`；
2. 白面块用 `.surface-card` / `.panel`，不要自己写 `border + bg + radius`；
3. 清单行用 `.panel-row`（52 高），不要在卡片里再套卡片；
4. 状态用 `StatusTag`（胶囊 + 圆点），语义色只表达状态；
5. 列表容器加 `.stagger`，可点卡片加悬停抬起，按钮已自带按下反馈；
6. 颜色 / 间距 / 圆角 / 时长一律引用令牌；新增视觉常量先加进 `tokens.css`。
