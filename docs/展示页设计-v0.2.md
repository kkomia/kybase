# 展示页设计 v0.2 · 终端 · 插座

> 2026-10-22 重做。上一版（纸与墨 · 信号蓝，v0.1）的问题：内容围着「判定」转，项目真正的卖点
> ——给 Agent 用的知识库插件、上传/解析/管理/检索、页码与源文件切片、分布与自主调参、免费解析栈
> ——没有在第一屏和主叙事里出现；视觉也偏稳妥。本版换方向，重新组织内容与页面。

## 一句话方向

**深色工作台 + 纸面证据。** 终端负责讲「插件怎么被 Agent 用」，纸面负责讲「它交回来的东西是什么」。
深色是工作台，纸面是证据；两者交替，形成长页的节奏。

- **北极星**：让读者相信「把文件交给 Agent，它真的能翻回原文、按页核对、按分布自己调」。
- **不沿用管理台语言**：管理台是产品界面；展示页是发布页，允许更黑、更硬、更有编辑感。
- **不是 AI 开发者页的默认配色**：没有紫蓝发光、粒子或弥散圆晕；用石墨黑、琥珀色与真实的终端文本。

## 首屏骨架

- 类型：说服型页面，首屏是「给 Agent 插一块知识库」+ 一个真实的 Agent 会话窗口。
- 骨架：**画面即界面**（终端就是主角），标题在左、说明与动作在右，下面直接接会话。
- 阅读路径：标题 → 一句定位 → 「接入插件 / 看一次返回」→ 会话里工具逐条点亮 → 一条带 `p.7` 的引用。
- 首屏必须让人看到：**11 个工具、两条传输、MIT 自托管、无匿名放行、契约指纹**。

## 视觉语言

- 底色 `#0a0b0c`，面板 `#101317`，纸面 `#f4f0e6` / `#faf7ee`。
- 强调色只有琥珀 `#eaa64a`；成功状态绿 `#8fca96`，链接蓝 `#9db4dc` 仅作辅助。
- 纸面上的「已核 P.7」用印章红 `#b23a20`，只在证据与页码相关处出现。
- 标题用 Noto Sans SC 700（自托管子集），字段与数字用 IBM Plex Mono，正文与纸面文档用系统中文。
- 直角、1px 线、无圆角卡片；面板靠 1px 线与明度差分层，不靠阴影堆叠。
- 数字、字段名、工具名全部等宽，让「契约」这件事在字体上就成立。

## 动效

- 首屏：标题两行从遮罩里升起；会话窗口整体上浮；用户消息、工具调用、命中卡片按顺序点亮；最后落一条引用。
- 区块：滚动触发一次，标题/表格/代码按阅读顺序出场，不重播。
- **滑动驱动的叙事（03 页码）**：360vh 的滚动距离里，一张纸 → 页标记 → 切块列表 → 命中卡片；
  右侧三章随进度切换，顶部三格进度条同步。往回滚倒放，跳转中段也立刻是正确画面。
- 减少动态效果 / `?motion=off`：页码叙事改成三段静态堆叠，所有区块直接可读；会话与返回示例保留完整内容。
- 调参演示：按钮切换 suggested / Agent 自主两态，参数、判定、命中数、代码一起变，不做与数据无关的装饰动画。

## 内容口径（重要）

- **示例数据**：会话、返回数值、工具示例、页码演示都是演示数据；页脚与对应图注写明
  「字段与判定口径取自当前实现，数值为示例」。
- **免费额度**：MinerU / PaddleOCR / 硅基流动的免费额度以服务商当期政策为准；仓库不带 token、不代收费用。
- **图像位置编码**：本版**没有**声称返回图像 bbox。代码里 `images` 表有 `page` / `bbox` 列、
  `SearchHitOut.image_ids` 也在契约里，但摄入侧目前没有把图片落库（`add_images()` 无调用方）；
  页面因此把「位置」讲成 **页码 + 页图原位**（`get_document_pages` 给页文字与整页原图链接，150 dpi），
  不写「图像坐标返回」。等这条链路真正落库后再改文案。
- **词面通道**：页面不写 BM25（实现是 Postgres tsvector + `ts_rank_cd`）；只写「向量 + 词面，RRF 融合」。
- **策略**：不写 fast / balanced / precise 预设；只说模式三档 + 参数 + 规则化的 `suggested`。
- **部署**：四件套 compose「一键起」尚未整体实测，页脚与部署区块如实写。
